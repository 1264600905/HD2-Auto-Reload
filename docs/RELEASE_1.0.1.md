# v1.0.1 — 手柄开火打断、AR-11 与下挂换弹

本地包：`build/Auto-Reload-v1.0.1.zip`，GUID 与旧版相同。替换旧包，保持仅启用一份，部署并重启游戏。此包尚未发布到 GitHub；最终版本按用户要求不再运行测试套件，由用户实测。

## 行为

- 非逐发、非站桩手持武器主动打断开火时，消费游戏汇总的 FIRE 动作再模拟 R。覆盖 Steam Input 默认右扳机；开火输入会等玩家松开后重新生效。移动和瞄准不在消费范围内。
- 逐发武器等待鼠标或手柄开火释放，发送前仍复核；站桩武器的新开火触发也识别统一动作。爆裂铳拉栓同样等待手柄开火释放。
- AR-11 主枪弹匣剩 1 发立即请求战术换弹；关闭战术总开关后保留空仓换弹。
- 主枪/下挂选择跟随本地人物 Wieldable 当前启用的实体，使用该实体自己的弹药路径。切换主枪、下挂、座位或武器时丢弃旧请求。适用于采用相同原生选择方式和已支持 Magazine、Rounds、Heat 组件的其他下挂；未支持的组件仍跳过。
- 逐发下挂默认打空自动换弹。“最后一发”按含膛内弹的总余弹计算；“第一发”按实际容量减 1 计算，仍等待松开火。主枪的 1 发阈值不会套到独立下挂上。

切到下挂后，本地 Wieldable 槽位 0 为 `{495, 496}`。旧读取器仍报告主枪 495；新读取器报告 `weapon_mode=underbarrel`、实体 496、父实体 495。

原生手持 R 路径 `0xA7CA42..0xA7CA59` 调用 `0x786920` 并启用 alternate 优先；该函数从 Wieldable 槽位 `+4` 取当前 alternate，未启用时返回主实体。新增读取仍执行完整组件表、实体身份与快照稳定性检查。

## 输入实现

FIRE 动作为 `{group=2, action=9}`（`0x900000002`），汇总状态位于输入 owner `+0x1C88`。原生输入消费入口为 `0x12FDE90`，消费时间 `-1` 表示等待释放。绑定时核对精确 PE 标识及动作索引、FIRE 读取、消费入口与消费管理指令；未核对的版本仅保留原有鼠标路径。弹药继续只读，换弹继续模拟 R；此版本新增原生输入消费调用，未调用原生换弹函数。

当前只读核对没有向游戏发送输入。最终包的手柄打断、自动 R 和其他下挂实际效果尚待部署实测。日志版本为 `revision=auto-reload-1.0.1`，新增 `FIRE_INPUT_SETUP`、`DEBUG_CONSUME_FIRE`、`weapon_mode` 与 `parent_weapon_entity`。
