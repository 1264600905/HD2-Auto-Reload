# v0.6.8 — 统一安装包与战术换弹设置

历史说明：GitHub 原始 v0.6.8 Release 包含 Mod Options Menu v1.3。下文记录后续本地独立菜单调整，该调整已随 [v0.6.9](RELEASE_0.6.9.md) 发布；当前推荐安装 v0.6.9。

下载 **Auto-Reload-v0.6.8.zip**。普通、战术与诊断版本已合并，包内仅包含自动换弹；单独安装支持 API 1 的 Mod Options Menu 后，战术换弹及日志输出均可在游戏内切换。未安装菜单时使用默认设置。

适用 Steam build **25327279 / 25480438**，依赖 **Bingus Shared Loader v18+ / API 1**。

## 更新内容

- 持续按住开火时，非站桩手持武器达到换弹条件会先松开左键，再在同一次更新内发送 R；保留右键瞄准。换弹后需重新按下左键开火。
- 22 个整弹匣武器的战术阈值统一为弹匣剩 1 发，包括 AR、SMG 等高速武器与 M-105 系列。
- 删除换弹延迟设置及连续射击/点击等待，首次请求固定零延迟。
- **战术换弹/Tactical Reload** 默认开启，关闭后仍保留打空自动换弹；所有设置始终显示，子选项保存值保留。
- **日志打印/Logging** 默认关闭，独立于战术开关。关闭时停止自动换弹日志写入和打印；切换日志不重置正在进行的换弹。
- 新增逐发武器阈值：**默认/Default、最后一发/Last Round、第一发/First Shot**。默认保留原武器配置；最后一发按总余弹 1 发触发；第一发在打掉第一发后尝试补弹。
- 新增 AC-8 阈值：**1发战术换弹、5发战术换弹、不战术换弹**，默认 1 发。不战术或战术总开关关闭时，须真正打空后重新按开火才触发。
- 选项名称及选择统一为中文/英文。“换弹不阻止开火”沿用原射击选项，不控制主动松左键；主动松键保持默认启用。
- 站桩武器原有规则保留；有限补发及身份、焦点和弹药复核继续生效。

## 安装

1. 替换旧 Auto Reload 包，保持仅一份自动换弹。
2. 单独安装并启用 Mod Options Menu（API 1）以使用游戏内设置；保留 Bingus Shared Loader v18+。
3. 部署并重启游戏，在 `Esc → MODS → 自动换弹/Auto Reload` 设置，点击 **APPLY / 应用（Tab）** 生效。

已有战术开关及射击选项保存值优先于默认值。旧换弹延迟保存值被忽略，不需要清空配置文件。需要排查时开启日志，文件位于 `%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/AutoReloadRounds.log`。

66 项控制器检查、8 项设置集成检查、7 项 Python 检查及组件表、上下文和读取接口检查通过；包内自动换弹 Lua 通过游戏自带运行时的编译检查。设置检查覆盖注册与保存恢复、选项始终显示；构建测试在没有菜单源码的独立目录运行，确认安装包仅含自动换弹资源。测试使用独立进程与输入桩，不向游戏发送测试输入。
