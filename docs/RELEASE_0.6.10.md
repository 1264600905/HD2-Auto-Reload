# v0.6.10：爆裂铳自动拉栓

爆裂铳被切枪等动作打断拉栓后，下一次开火可能只执行拉栓。新版本读取原生待拉栓标记，确认状态和输入允许后自动补一次左键短按，让游戏执行自身的拉栓动作。

安装包为 `build/Auto-Reload-v0.6.10.zip`，GUID 与旧版本一致，替换原自动换弹包，保持只启用一份，部署后重启游戏。依赖 Bingus Shared Loader v18+ / API 1。菜单需要单独安装支持 API 1 的 Mod Options Menu；包内只包含自动换弹。运行版本行应为 `revision=auto-reload-0.6.10`。

## 设置和行为

`MODS → 自动换弹/Auto Reload → 爆裂铳自动拉栓/Eruptor Auto Bolt` 默认开启，修改后 APPLY，菜单负责保存和恢复；未安装菜单也默认开启。该设置独立于战术换弹，关闭战术换弹不会关闭拉栓；关闭拉栓不会关闭原有换弹。默认开火键须为鼠标左键。

只对本地玩家当前选中的手持 R-36 爆裂铳生效。读取 `WeaponReload` 运行时 `0x800` 标记、有效 `WeaponData +0x4b0` 的动作 ID `2660`，同时核对武器和玩家实体的 Ability 动作状态，避免打断挂在玩家实体上的换弹等动作；不使用弹匣余量或弹膛 token 猜测拉栓。最后发送前再次读取完整上下文，任何身份或状态变化均不发送。

玩家正按住左键/R、自有 R 或鼠标尚未释放、武器动作进行中、UI 屏幕栈非空、失去游戏焦点或上下文无效时等待。未知 UI、动作、布局和读取失败均不发送自动开火。菜单保护来自 UI 屏幕栈，不能声称所有未进入该栈的聊天或第三方覆盖层已经实测。

左键短按最多保持 80 毫秒，动作开始或待拉栓标记清除可提前释放；只释放本模组拥有的短按。标记清除后不继续补按。若系统接受输入但状态仍待拉栓，最多发送三次，相邻至少间隔 1 秒；动作进行中不重试。玩家切枪、失焦、关闭选项或退出游戏会释放自有输入并取消旧请求。鼠标松开失败时保留所有权并重试，期间不发送新的开火或 R。

已有换弹路径先执行，自动拉栓与自有 R 互斥。本次保留原有战术阈值、逐发开火优先、站桩和载具规则。

## 版本与诊断

新拉栓字段仅启用于已核对的 build 25480438（timestamp `0x6ab3b43f`），并检查对应原生指令片段。旧 build 25327279 继续自动换弹，自动拉栓显示 `unsupported_build`；签名或可选组件不可用时只禁用拉栓读取，不将其当作全模组初始化失败。

开启“日志打印/Logging”并 APPLY 后，`AutoReloadRounds.log` 中可见：

- `OPTIONS_APPLIED ... eruptor_auto_bolt=true/false`：生效的开关。
- `CTX ... bolt_status=... bolt_flags=... bolt_action_active=... bolt_player_action_active=... bolt_gameplay_input=...`：读取结果、武器/玩家动作与界面门槛。
- `BOLT_REQUEST sent=... detail=... attempts=... entity=...`：仅表示输入请求结果。
- `BOLT_CONFIRMED flags_cleared=true action_active=...`：原生待拉栓标记已清除，动作仍可能正在收尾。

日志默认关闭；日志切换不重置换弹或拉栓的请求状态。`scripts/read_live_context.lua` 也输出新字段，用于不发送输入的实机采集。

## 验证

使用安装游戏的 `lua51.dll` 在独立测试进程运行 Lua 检查，输入接口全部为记录桩。72 项原有换弹、19 项拉栓、13 项完整读取链、9 项含真实菜单保存恢复的设置检查、6 项静态 map、2 项 Windows API 初始化及 7 项 Python 检查通过。完整生成入口仅编译检查而未执行，zip 完整性和 manifest 也通过。验证输出保存在 `build/validation-v0.6.10.txt`。

分析阶段的手动实机对照已确认：待拉栓 `0x800` → 动作 `2660` 开始 → 标记清除 → 动作结束，弹匣始终 3 发。新包自动 SendInput 尚未实机验证。部署后需检查：射击后切副武器中断再切回自动完成、正常拉栓不多开一枪、开关关闭/保存恢复、按住开火、Esc/地图、换弹中断及最后一发。

构建：`python scripts/build.py`。新增测试：`luajit tests/test_eruptor_bolt.lua`，其余检查沿用 README 中的完整测试命令。
