# v0.4.0 测试版

空仓等待时间从 3 秒改为 1 秒。项目已整理为独立仓库，可直接用 Python 标准库打包。

下载附件 `Auto-Reload-v4.zip` 替换旧版本，并保持 Bingus Shared Loader 启用。
逐发弹药和普通弹匣分支支持主手、副武器及支援武器。

散热型能量武器尚未启用自动换弹：本包扩充了定点只读诊断，供下一轮实机采集过热状态证据。
请用散热型武器射击至过热、等待并手动 R 换散热器，测试后检查 `AutoReloadRounds.log`。
不按武器外观过滤，因此使用弹匣系统的能量武器已有相应路径支持。

验证：16 项 Lua 控制器/读取/输入检查、3 项完整 map 检查、2 项打包测试通过；生成 Lua 语法检查通过。
游戏 build 24826606 的 EXE/game.dll SHA256 已验证。离线检查不代表实机换弹成功。
