# Auto Reload v1.0.0 正式版

将当前自动换弹模组发布为 1.0 正式版，统一运行版本和安装包版本为 `1.0.0`，沿用 v0.6.13 的功能行为、GUID 和已有设置。

## 功能

- 普通空仓自动换弹、战术换弹及逐发武器开火优先；支持弹匣、逐发和已核对的散热器更换路径。
- 定期复查是否仍需换弹或拉栓：**0.2 秒（默认）**、**0.5 秒**、**1 秒**、**关闭**，游戏内 APPLY 后生效并保存。
- 爆裂铳自动拉栓，沿用原生标记、动作和输入复核，相邻拉栓请求至少间隔 1 秒。
- 包含原生坦克炮手、乘客手持武器和已核对车载机枪的换弹修复。
- 保留战术总开关、逐发阈值、AC-8 阈值、开火优先与独立日志设置。

## 安装

下载 `Auto-Reload-v1.0.0.zip`，在 Mod 管理器中替换旧 Auto Reload，保持只启用一份，部署后重启游戏。旧 Lua 不会随 ZIP 替换而刷新。

依赖 **Bingus Shared Loader v18+ / API 1**。游戏内设置需单独安装 **Mod Options Menu API 1**；未安装菜单时使用默认设置。换弹键须为 R，爆裂铳开火键须为鼠标左键。

沿用 Steam build `25327279` / `25480438` 的已有适配，爆裂铳自动拉栓仅适配已核对的 `25480438`。只读检查状态并模拟输入，不写弹药或游戏内存，不调用游戏函数。

## 构建与核对记录

构建命令：`python scripts/build.py`，输出 `build/Auto-Reload-v1.0.0.zip`。日志版本应为 `revision=auto-reload-1.0.0`。

按用户要求本次未运行测试套件。近期载具修复已在运行中的游戏完成只读状态核对，自动输入效果仍待部署实测；证据见 [坦克和乘客修复](https://github.com/1264600905/HD2-Auto-Reload/blob/v1.0.0/docs/RELEASE_0.6.12.md) 与 [车载机枪支持](https://github.com/1264600905/HD2-Auto-Reload/blob/v1.0.0/docs/RELEASE_0.6.13.md)。
