# Build 25480438 compatibility

Verified on 2026-09-24 against the running game with read-only process access.

- Steam app manifest: build 25480438.
- game.dll SHA256: `2e2c3b7c2500646dadd5f2b4c6e0504dbb7e7896139f64cddc0d1813c718f51e`.
- helldivers2.exe SHA256: `f5fee03dcfdb2e553a4752c283590950ac13316b376d8196aa556ff0400d5f06`.
- PE timestamp: `0x6ab3b43f`; SizeOfImage: `0x4744000`.

The installed addon logged `unsupported_game_build`. All 13 existing layout
signatures match at their original addresses. The Magazine manager and its full
76-byte layout signature, and both Heat signatures, also match exactly.
The native resource getters at 0x4f32f0, 0x4fd8e0 and 0x50dd30 retain their
component slots, entry counts and record strides.

All bytes in the live Magazine (540 entries), Rounds (50 entries) and Heat
(58 entries) resource/index maps match the stored 25327279 maps. Those files
are deliberately reused rather than duplicating identical data.

Version 0.6.2 accepts both exact timestamp/image-size pairs and retains all
instruction, full-map, entity and snapshot stability checks. The optional
build-time SHA256 check accepts only a complete matching DLL/EXE pair.
The external reader now uses the same build verifier as the addon.

The real reader passed PE and layout validation, then returned
`waiting_for_avatar`. This verifies safe handling of the current missing-avatar
state, not equipped-weapon counters or automatic reload. Actual input and reload
behavior require deployment, a game restart and a gameplay test.

## Equipped-weapon follow-up

After restart, version 0.6.2 reached a separate initialization failure:
`missing declaration for symbol 'SendInput'`. Version 0.6.3 supplies the missing
declaration independently while preserving compatibility with an existing
declaration. Fresh Windows LuaJIT processes verified both absent and preexisting
declarations without sending input. All 51 behavior tests, 6 Python tests,
context tests and full component-map tests passed.

The live reader subsequently returned `context_observed`, slot 1, resource
`006e44327bb953fe`, `weapon_rounds`, `chamber_ready`, magazine count 3.
The snapshot passed all entity and stability guards (93 reads, 2352 bytes).
This confirms actual equipped-weapon reads on the updated game. Automatic
input still requires deploying version 0.6.3 and restarting the game.
