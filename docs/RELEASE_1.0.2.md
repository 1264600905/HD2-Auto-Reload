# Auto Reload v1.0.2

修复手柄持续开火时无法被自动换弹打断，以及下挂模式仍读取主枪弹药的问题，并补充 AR-11 与 AC-8 的战术换弹阈值。

## 更新内容

- **手柄开火打断**：在已核对的游戏 build `25480438` 上消费游戏汇总的 FIRE 动作，再模拟 R，覆盖 Steam Input 默认右扳机。开火输入在玩家松开后重新生效，移动和瞄准不在消费范围内。
- **开火优先**：逐发武器在鼠标或手柄按住开火时等待，发送前再次复核；爆裂铳拉栓同样等待开火释放。站桩武器仍需打空后重新按开火。
- **AR-11 主枪**：弹匣剩 1 发时立即战术换弹。
- **AR-11 下挂霰弹**：默认按包含膛内弹的总余弹剩 1 发触发；沿用逐发“最后一发／第一发”设置，并等待松开火。
- **通用下挂识别**：跟随本地人物当前启用的下挂实体，读取其独立 Magazine、Rounds 或 Heat 弹药组件，切换模式后丢弃旧请求。其他未配置的逐发下挂默认打空自动换弹，并沿用逐发阈值选项；未支持的组件仍跳过。
- **AC-8 一发战术换弹**：弹仓阈值改为 0，保留膛内最后 1 发；5 发模式保持原阈值，不战术模式仍需真正打空后重新按开火。

本版包含此前未单独发布的 v1.0.1 手柄与下挂修复。弹药继续只读，换弹继续模拟 R；新增原生输入消费调用，不直接调用原生换弹函数。

## 安装

下载本 Release 的 `Auto-Reload-v1.0.2.zip`，在 Mod 管理器中替换旧 Auto Reload，保持只启用一份，部署后重启游戏。GUID、菜单设置 ID 和已有保存值沿用。

依赖 Bingus Shared Loader v18+ / API 1；游戏内设置需单独安装 Mod Options Menu API 1。默认换弹键须为 R。新手柄输入路径仅启用于已核对的 build `25480438`，其他已支持版本保留原有鼠标路径。

## 验证状态

按用户要求，未运行最终版本测试套件；游戏内实际效果由用户实测。已只读确认 AR-11 主枪资源 `a8a91eb54892b6b2` 与下挂霰弹资源 `b9c209b4f99b5335`，下挂容量为 4 发（弹管 3 发、膛内 1 发）。其他下挂未逐一实机确认。

运行日志版本应为 `revision=auto-reload-1.0.2`。开启日志后可查看 `FIRE_INPUT_SETUP`、`DEBUG_CONSUME_FIRE`、`weapon_mode` 与 `parent_weapon_entity`。
