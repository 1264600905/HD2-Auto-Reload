# v1.0.4：持续打断开火测试版

安装包：`build/Auto-Reload-v1.0.4.zip`。运行版本：`auto-reload-1.0.4`。

## 行为

原本会主动打断开火的普通／战术自动换弹，在成功发送 R 后启动 **0.5 秒**的压制窗口。在每帧游戏更新中清除期间重新出现的合并开火动作和鼠标开火输入。手柄沿用已验证的游戏合并开火动作，鼠标保留松键路径。

同一个窗口只在启动时设定截止时间，逐帧处理不续期；到期停止压制。另一次新的自动换弹如果仍属于需要打断开火的类别，会启动它自己的半秒窗口。发送 R 失败不会启动新的窗口。

原生开火消费改为只清除当前帧，由本模组的固定截止时间控制持续处理，避免使用“直到物理松手”的不限时消费。窗口结束后停止干预，不发送模拟开火来恢复按键；后续开火由玩家和游戏处理。

## 排除范围

- **逐发装填武器全部排除**，包括已配置的逐发下挂与机甲霰弹。玩家按住开火时仍等待，松手后再按原规则补弹。
- **AC-8 机炮全部排除**，包括 1 发／5 发战术换弹、关闭战术换弹及不战术换弹模式。
- 原本不主动打断开火的站定装填武器和载具换弹继续沿用原规则。

这些排除只针对本次半秒开火压制，仍保留 v1.0.3 的随机换弹等待。

## 清理与原设置

- 切枪、换座、上下车、更换人物、失焦、人物失效、快照失效或应用换弹设置时，取消旧窗口。
- 监测到原生输入对象变化时停止后续消费，避免沿用旧指针。
- 仅切换日志不取消窗口；退出时明确清理窗口。
- 开火压制窗口内不会通过自动拉栓再注入开火。
- 保留原 R 按住时长、随机延迟范围 80–150 毫秒，以及拟合平均值 133.5821611111111 毫秒、方差 306.24582071126537 毫秒²。

## 验证

全部验证在独立进程中进行，原生调用与输入由替身记录，未向游戏发送任何真实输入：

- 17 项合并开火输入检查：包含窗口内反复开火、半秒边界、初始未开火、鼠标备用路径、失焦取消、输入对象变化、发送失败、不主动打断的请求和拉栓互斥。
- 7 项开火压制范围与清理检查：覆盖机炮各模式、逐发及下挂武器、弹药恢复后窗口继续、武器与人物变化、失效状态和设置取消。
- 75 项原控制器、20 项随机延迟、19 项拉栓检查通过。
- 菜单保存恢复、完整 Lua 入口语法和安装包检查通过。

半秒窗口按游戏更新执行，到期后第一帧停止；实际输入处理仍受游戏帧率影响。持续消费对真实鼠标、手柄的表现，以及换弹动作是否成功，尚待用户安装后实测。

## 安装

导入管理器替换旧版，与原有依赖一起部署，再重启游戏。管理器标识、资源路径和菜单保存值沿用；本版仅生成本地测试包。
