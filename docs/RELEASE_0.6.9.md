# v0.6.9 — 逐发满弹判断与开火优先修复

安装包：`Auto-Reload-v0.6.9.zip`，从 [GitHub Release](https://github.com/1264600905/HD2-Auto-Reload/releases/tag/v0.6.9) 下载，或构建后在 `build/` 获取。替换旧自动换弹，保持只启用一份；保留 Bingus Shared Loader。适用 Steam build 25327279 / 25480438。

需要游戏内设置时单独安装支持 API 1 的 Mod Options Menu；v0.6.9 不再内置菜单或条件显示补丁，全部设置始终显示。未安装菜单时使用默认设置。安装后部署并重启游戏，已有设置保存值继续沿用，日志默认关闭。

## 修复行为

- 第一发模式使用当前选中弹匣的生效容量，按 `总余弹 <= 容量 - 1` 请求。总余弹为弹匣余弹，加独立枪膛中最多一发；非零 token 是弹药标识，不是数量。满装为“容量−1＋膛内1发”时不再循环请求。
- 全部 11 条现有逐发规则在按住左键时暂停自动 R，松手后再次复核弹药并补弹。覆盖默认、最后一发、第一发，以及关闭战术换弹后的空仓处理。
- 逐发武器不主动松开左键；AC-8、其他整弹匣武器及站桩武器沿用各自规则。首次请求与连续补弹在发送前都复核开火状态，避免读取弹药期间重新开火造成强制换弹。
- 保留有效容量校验、实体覆盖、选择弹匣、焦点和武器身份检查。无有效容量时跳过第一发提前补弹，保留原有已确认的空仓处理。

2026-10-12 实机日志确认 SG-97 满弹为“弹匣6＋膛内1＝容量7”，GL-15 为“弹匣3＋膛内1＝容量4”，第一发模式的满弹判断口径正确。两把武器均记录到开火等待、松手补弹和弹药恢复，用户反馈测试无明显问题。其他逐发武器与模式组合仍以离线覆盖为主，见 [实机日志核对记录](RELOAD_LOG_ANALYSIS_2026-10-12.md)。

## 一次启动完成测试

1. 加载并部署 v0.6.9 后启动游戏，在 `Esc → MODS → 自动换弹` 开启 **日志打印/Logging**，选择 **第一发/First Shot**，点击 **APPLY**。已有日志保存值沿用，可能仍为关闭。
2. 装备出现问题的逐发武器。满弹静置数秒，按一次 F8 标记；预期没有自动 R。
3. 单发射击并松开左键，观察是否补弹；补回满弹后再按一次 F8，预期停止补弹请求。
4. 按住左键持续射击或连续扣扳机，越过阈值；预期不会被模组强制停止。松开后再观察补弹。F8 可标记每组操作。
5. 可在同一会话将逐发选项切换为默认、最后一发或关闭战术换弹并 APPLY，检查开火优先规则。设置切换无需重启。
6. 如需进一步排查，保持任务运行后使用下面的 Python 采集，重复“满弹 → 射击 → 松手补满”。无需再次启动游戏。本次发布依据已有实机日志完成核对，没有额外执行内存采集。

日志：`%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/AutoReloadRounds.log`。确认存在 `LOGGING_ENABLED revision=auto-reload-0.6.9`；新 `PER_ROUND_STATE` 行在状态变化时记录：

| 字段 | 含义 |
| --- | --- |
| `mag` / `chamber_token` / `total` | 弹匣余弹、膛内弹药标识、总余弹 |
| `capacity` / `selected_mag` / `config_source` | 生效容量、当前弹匣选择、实体覆盖或资源模板 |
| `mode` / `basis` / `count` / `limit` / `eligible` | 当前设置、比较口径、比较值、阈值和是否满足条件 |
| `lmb` / `action` | 开火键状态，以及 `outside_threshold`、`wait_for_fire_release` 或 `reload_eligible` |

相同状态不重复输出这类诊断。原有 `RELOAD_REQUEST` 保留；输入被系统接受不代表原生换弹已完成。

## Python 只读采集

```powershell
python -B scripts/capture_reload_context.py --samples 300 --interval-ms 100
```

自动定位唯一的 `helldivers2.exe` 与加载的 `game.dll`，使用该游戏的 `lua51.dll` 在外部 Python 进程运行现有读取器。输出 `build/reload-context-v0.6.9.log`，包括样本时间、左键状态、当前弹匣余弹、枪膛、容量和配置来源。多个游戏进程时可指定 `--pid`，也可用 `--output` 为不同武器保存独立文件。

进程句柄只有查询与读取权限；不运行模组入口、注册回调、写游戏内存或发送按键。当前包仍通过原生 R 输入换弹。
