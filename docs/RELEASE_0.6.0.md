# v0.6.0 — 可配置战术换弹与即时换弹修复

适用 Steam build **25327279**，依赖 **Bingus Shared Loader v15+ / API 1**。

## 更新内容

- 新增构建前可编辑的武器配置表，支持弹匣阈值、逐发续装和即时触发。
- 移除普通空仓及需要更换的烧毁散热器的固定 1 秒等待。
- 应用高速武器配置：AR 枪族（不含 JAR）、BR-14、SMG 系列、M7S、StA-11、P-2、P-19、M6C/SOCOM 在弹匣 ≤3 发时请求换弹；M-105 和手持 MK3 在 ≤10 发时请求。这些武器不等待 0.1 秒。
- 其他战术武器仅在进入换弹窗口后计算点击延迟：从 0.1 秒起步，快速连续点击可延长至 0.2、0.4、0.6 秒。窗口外点击不累积，离开窗口即重置；按规则计数剩 1 或 0 发时立即请求。
- 保留此前调整的 0 发弹匣阈值；膛内弹不计入弹匣。SG-97、GL-15 保留原有总弹量口径。
- 移除手动换弹抑制，修复 M-105 手动按 R 后继续射击至打空仍无法自动请求的问题。
- 模拟 R 的松开与再次按下分属不同更新帧；发送失败不消耗重试机会。即时复核期间弹药继续减少不再取消请求。
- MG-43、GR-8 等站桩换弹武器仍要求确认空仓后重新点击射击。

## 下载与安装

| 安装包 | 用途 |
| --- | --- |
| `Auto-Reload-v0.6.0-tactical.zip` | 推荐：启用全部可配置战术规则，包含上述高速武器阈值 |
| `Auto-Reload-v0.6.0.zip` | 仅普通空仓换弹，不启用战术阈值 |
| `Auto-Reload-v0.6.0-tactical-debug.zip` | 战术规则版，附详细诊断日志 |
| `Auto-Reload-v0.6.0-debug.zip` | 普通空仓版，附详细诊断日志 |

所有包沿用同一 GUID，只启用一份。替换旧包，与 Loader 一起部署后重启游戏。默认换弹键须为 R。

日志：`%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/AutoReloadRounds.log`。版本为 `auto-reload-0.6.0` 或 `auto-reload-0.6.0-debug`；战术版应记录 `tactical_reload=true reload_delay=0`。

## 验证与已知限制

已通过离线控制器、输入时序、组件映射、读取链和打包测试，包含 M-105 手动 R 后打空的回归场景。最终修复尚未得到实机完整确认；系统接受按键不代表游戏完成换弹，游戏动作限制和备用弹药仍由游戏处理。

MG-43 的历史装备崩溃报告尚未确认原因，本版按此前要求保留试验性读取，不宣称修复该崩溃。仅兼容上述游戏构建版本。
