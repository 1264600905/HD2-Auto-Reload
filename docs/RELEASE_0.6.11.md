# v0.6.11：可设置的定期复查

新增 `MODS → 自动换弹/Auto Reload → 定期检查/Periodic Check`，四个选项依次为 **0.2 秒（默认）**、**0.5 秒**、**1 秒**、**关闭**。修改后 APPLY，菜单负责保存和恢复；未安装菜单时使用 0.2 秒。

定期检查补充原有即时判断，复用当前帧的武器快照，每次发送输入前仍重新读取并核对当前武器和弹药。普通或战术换弹条件仍成立、上一次自动 R 未解决时，允许按选定周期重新尝试；与上次 R 请求至少间隔选定周期。逐发武器按住开火时仍等待，必须打空后重新点击射击的站桩等武器继续遵守原规则。

爆裂铳在原三次请求后仍有待拉栓标记时，定期复查可继续尝试。相邻左键请求仍至少间隔 1 秒，检查周期不会缩短此限制；每次核对身份、原生 `0x800` 标记、动作、UI 与玩家输入。标记清除后停止，拉栓开关关闭时不尝试。

关闭定期检查只关闭补充复查，原有即时换弹、特定武器重试、连续补弹和最多三次自动拉栓仍保留。切换设置时复查计时重置；失焦期间停止计时，恢复焦点后重新等待一个周期，长帧不会累计补发多次请求。

安装包为 `build/Auto-Reload-v0.6.11.zip`，GUID 沿用旧版本。替换旧包，保持只启用一份，部署后重启游戏。依赖 Bingus Shared Loader v18+ / API 1；设置菜单单独安装 Mod Options Menu API 1。日志版本为 `revision=auto-reload-0.6.11`，`OPTIONS_APPLIED` 中的 `periodic_check=1/2/3/4` 分别对应四个选项，`periodic_check_seconds` 显示秒数或 `off`。

构建命令：`python scripts/build.py`。按用户要求本次只完成源码修改和打包，不运行测试；新行为尚未实机验证。原有拉栓适配范围和诊断说明见 [v0.6.10 说明](RELEASE_0.6.10.md)。
