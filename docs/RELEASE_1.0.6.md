# v1.0.6：修正开火屏蔽模式

安装包：`build/Auto-Reload-v1.0.6.zip`；日志版本：`auto-reload-1.0.6`。

v1.0.5 的调用实际进入游戏的输入消费模式。这个模式有两种解除条件：时长到期，或者玩家松开开火。模拟鼠标松开、手柄放开扳机，都会使它在半秒前解除。上一轮仅检查时间计算，遗漏了后面的松开取消分支；测试替身也遗漏了这个行为，因此不能证明实机有效。

本轮先保存失败日志，再只读检查重新启动的游戏。日志确认四十七次调用均已发出，没有在失败前发生失焦或切枪取消；反器材步枪一次在请求后约一百零九毫秒消耗了膛内最后一发。读取游戏输入更新代码后确认模式区别和提前取消的路径。

本版仍在换弹前清除当前开火，但成功发出换弹键后改用游戏固定时长屏蔽模式，设为半秒。初始未按开火、窗口内松开后再按，都保持屏蔽；逐帧维护不会把它改回原来的消费模式，也不会续期。切枪、人物失效、失焦、设置取消和结束时解除屏蔽，保留原指针与版本校验。

逐发装填、逐发下挂、AC-8 机炮排除范围和 80–150 毫秒随机等待拟合参数不变。

按用户要求只做针对性检查。依据读到的实际流程补充“松开再按”复现，确认旧实现失败，再检查修正结果、半秒边界、排除范围、语法和包内容。没有向运行中的游戏注入输入或部署新包；实际游戏效果仍待用户安装确认，不能撤回游戏已经接收并排队执行的射击。

替换旧包、部署并重启游戏。新日志中的开始记录应包含 `mode=fixed_time`，并出现 `DEBUG_BLOCK_FIRE`。
