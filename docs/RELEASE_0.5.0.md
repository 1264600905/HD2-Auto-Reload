# v0.5.0 — 能量武器自动换弹

支持 Steam build **25327279**，依赖 **Bingus Shared Loader v15+ / API 1**。

- 新增散热型能量武器自动换散热器：确认过热锁定后等待 1 秒，再模拟 R；持续开火同样等待满 1 秒。
- 普通升温、充能及可自行恢复的冷却锁定不触发换弹。
- 适配新版玩家、武器及弹药组件布局，更新完整资源表校验和 Rounds 配置记录长度。
- 发送前重新核对武器实体、槽位和状态；手动 R 会抑制重复自动请求。
- 保留主手、副武器、支援武器支持，只读游戏状态，不改弹药、不写游戏内存、不调用游戏函数。

用户已确认功能测试通过，能量武器可正常使用。此前 34 项离线检查及生成 Lua 语法检查通过；不代表所有武器和场景均已覆盖。

下载 `Auto-Reload-v5.zip`，在 Mod 管理器中替换旧 Auto Reload，与 Loader 一起部署后重启游戏。沿用旧 GUID，请保持只启用一份。默认换弹键须为 R；日志版本为 `auto-reload-5`。

旧版 v4 不支持本次游戏更新。游戏再次更新后需重新验证。资源 `11c27d3babb38956` 继续跳过。
