# v0.6.4 — 等离子制裁者修复与载具换弹

支持 Steam build `25327279`、`25480438`，依赖 **Bingus Shared Loader v15+ / API 1**。
主干继续只读检查状态并模拟 R，native 实验后端保留在 `native-test` 分支。

## 本版修复

- SG-8P 等离子制裁者取消剩 8 发时提前换弹，改为打空后换弹。
- TD-220 堡垒主炮炮弹打空后自动换弹。
- TD-110 风暴漩涡主炮当前 300 发弹匣打空后自动换弹。
- EXO-55 突破重型霰弹枪：战术版弹匣余量 ≤5 发时开始逐发补弹，补至 6 发后停止请求；普通版仅空仓触发。
- 载具中改为读取本地人物当前操控的武器，避免继续使用人物物品栏的手持武器计数；上下车、换座位或武器选择改变时取消旧请求。

## 下载与安装

| 安装包标签 | 用途 |
| --- | --- |
| `[战术换弹]Auto-Reload-v0.6.4-tactical.zip` | 推荐：启用战术阈值，突破机甲 ≤5 发补弹 |
| `[普通换弹]Auto-Reload-v0.6.4.zip` | 空仓换弹，突破机甲也须打空 |
| `[战术换弹]Auto-Reload-v0.6.4-tactical-debug.zip` | 战术版，附详细诊断日志 |
| `[普通换弹]Auto-Reload-v0.6.4-debug.zip` | 普通版，附详细诊断日志 |

GitHub 附件显示完整中文标签，平台会过滤实际附件文件名中的中文与方括号；本地构建 ZIP 保留完整前缀。
四个包沿用同一 Mod GUID，只启用一份。关闭游戏，在 Mod 管理器中替换旧包，与 Loader 一起重新部署后重启游戏。默认换弹键须为 R，模组不支持热重载。

日志位置：`%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/AutoReloadRounds.log`。
`START` 行应含 `revision=auto-reload-0.6.4`，诊断包另含 `-debug`；战术版记录 `tactical_reload=true reload_delay=0`。

## 验证与适用范围

战术诊断版在 build `25480438` 的战斗场景中完成上述四项测试，用户已确认通过。日志同时记录了对应阈值的 R 请求与弹药恢复。
普通版空仓逻辑通过离线测试，本次未另行安装普通版实测。
54 项控制器行为测试、6 项 Python 测试、完整组件表、人物/载具读取链及两种 Windows FFI 初始化检查通过。

载具支持此次核对的 Pilot `role=4` 操作位：突破座位 0、堡垒和风暴漩涡座位 1。两个坦克实测使用现有单人载具模组的 Pilot 操作状态。
原生 Gunner `role=2`、乘客和其他载具武器当前跳过。资源 ID、指令校验及实测证据见 [测试记录](https://github.com/1264600905/HD2-Auto-Reload/blob/v0.6.4/docs/VEHICLE_RELOAD_0.6.4.md)。

备用弹药与游戏动作限制仍由游戏处理。MG-43 历史装备崩溃报告保留既有说明与试验性读取范围。
