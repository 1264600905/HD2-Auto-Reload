# v1.0.5：半秒开火屏蔽修复

安装包：`build/Auto-Reload-v1.0.5.zip`；日志版本：`auto-reload-1.0.5`。

上一版仅在脚本中记录半秒，向游戏传入的屏蔽时长为零。游戏下一次处理输入就会判为到期，因此可能重新接受开火。

本版在成功发送自动换弹键后，向游戏设置一次五百毫秒的开火屏蔽，即使当时未按住开火也生效。后续逐帧清除不会延长原截止时间。切枪、人物或座位变化、失焦、应用设置和退出时，同时解除游戏里的屏蔽；输入对象变化后不再调用旧对象。日志增加 `DEBUG_FIRE_INTERRUPT_BEGIN` 和 `DEBUG_FIRE_INTERRUPT_END`。

逐发装填武器、逐发下挂和 AC-8 机炮仍全部排除。其余原有适用范围保持，反器材步枪包含在内。随机等待仍为 80–150 毫秒，平均值与方差的拟合参数不变。

按用户要求仅做针对性检查：开火输入、半秒边界、模拟游戏在脚本之后重新处理输入、提前取消、逐发及机炮排除、完整入口语法、安装包内容。未运行完整测试套件，也未向运行中的游戏注入测试输入；已经排队执行的射击不能追溯撤回，实际手感仍需部署后确认。

在管理器中替换旧包、部署后重启游戏。包标识和已有菜单设置保持不变。
