# v0.6.13：补充车载机枪换弹

2026-10-13 用户停留在当前载具炮手位，旧版实际日志仍为 `auto-reload-0.6.10`；本地 v0.6.12 只读读取器虽已支持原生炮手角色，却因当前机枪不在载具支持表中返回 `vehicle_weapon_unsupported`。本次补充该已核对武器，保留原有坦克、乘客和定期检查修复。

| 字段 | 当前游戏的只读结果 |
| --- | --- |
| 载具类型 / 座位 / 角色 | `0x1A` / 4 / `role=2` |
| 当前 Wieldable 主槽位武器资源 | `085c1edb038ec24e` |
| 弹药组件 | `weapon_magazine`，已通过完整组件表与实体身份核对 |
| 弹匣 / 膛内 | 0 / 0 |
| 修复后上下文 | `context_observed`，`weapon_context=vehicle` |

新增载具支持项同时限定类型、座位、资源和组件路径；普通和战术模式都使用空仓阈值 0。弹匣和膛内均为空时沿用自动 R 请求与现有四档定期检查，弹药恢复后停止。换座、上下车、换武器、过渡或失焦时仍取消旧请求。

采集只读，不安装模组回调、不写游戏内存、不发送按键；修复后的三次采样均识别当前机枪空仓。样本位于本地 `build/current-vehicle-before-v0.6.13.log` 与 `build/current-vehicle-after-v0.6.13.log`，不提交完整个人日志。本次未运行测试套件，自动输入效果待新包实际部署后确认。

安装包：`build/Auto-Reload-v0.6.13.zip`。替换旧自动换弹包，部署并重启游戏，保持只启用一份。GUID、Loader 依赖与菜单保存值沿用，构建命令为 `python scripts/build.py`。启动或开启日志后的版本应为 `revision=auto-reload-0.6.13`；运行中的旧 Lua 不会随 ZIP 替换而刷新。
